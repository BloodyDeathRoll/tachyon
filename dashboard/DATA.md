# dashboard/data.json — every field and its source

Generated by `python -m dashboard.data`. Nothing here is invented; a field with no source yet is
`null` and the page designs the empty state.

| Path | Source |
|---|---|
| `generated_at` | clock at generation (UTC) |
| `states.main / exceptions / waiting_on_human` | `spine/state.py` |
| `totals.needs_you / live / scheduled / in_production / emergency_stop` | sums over clients |
| `clients[]` | one per folder under `clients/` |
| `clients[].name / display / handle` | folder name; handle from the Graph API (`rosasurfapp`) |
| `clients[].grants.{page_id, ig_user_id, auto_approve_pillars, auto_reply, emergency_stop}` | `grants.yaml` |
| `clients[].posts[]` | `tachyon.db posts` joined with `posts/<slot>/*` |
| `posts[].slot_id / state / scheduled_at / published_at / pillar / angle / hook_formula / cta / engine / trial / experiment_id / qa_rounds / ig_media_id / permalink / note / updated_at` | `posts` row |
| `posts[].state_group` | `needs_you` (NEEDS_APPROVAL, NEEDS_INPUT, MANUAL_HANDOFF, FAILED) · `in_production` (IDEA…QA) · `scheduled` (APPROVED, QUEUED, PUBLISHING) · `live` (PUBLISHED, MEASURING) · `done` (ANALYZED) · `rejected` |
| `posts[].age_hours` | now − `published_at` |
| `posts[].length_s / source_asset / operator_overrides` | `posts/<slot>/meta.json` |
| `posts[].qa.{spec, verdict, verdict_note, lines[], warns[]}` | parsed from `posts/<slot>/qa.md` |
| `posts[].caption / first_comment` | `posts/<slot>/caption.txt`, `first_comment.txt` |
| `posts[].files.{video, cover}`, `media_url`, `cover_url` | existence of `video.mp4`, `cover.jpg`; URLs served by the dashboard server |
| `posts[].metrics.by_window.{24h,72h,7d}` | `metric_snapshots` where `source = ig_media`; raw Meta metrics plus `_derived` (sends_per_reach, likes_per_reach, saves_per_reach, follows_per_reach, comments_per_reach, hold) |
| `posts[].metrics.latest / windows_done / next_window_at` | derived from the above and `spine/measure/insights.WINDOWS` |
| `clients[].groups` | count of posts per `state_group` |
| `clients[].needs_you[] / live[]` | filtered `posts[]` |
| `clients[].account_daily[]` / `account_latest` | `metric_snapshots` where `source = ig_account`, one per day: views, reach, accounts_engaged, total_interactions, follows_and_unfollows, profile_links_taps, followers_count, media_count |
| `clients[].experiments[]` | `experiments` table |
| `clients[].conversions[]` | `conversions` table (GA4 / DM / comment), last 50 |
| `clients[].costs[]` | `costs` table summed by kind |
| `clients[].engage.{date, file, items[], done, total}` | `engage/<today>.md` exists? + `engage_log` rows for today |
| `clients[].calendar` | `calendar.yaml` (null until Plan runs) |
| `clients[].reports[]` | file names under `reports/` |
| `clients[].lessons` | `lessons.yaml` (null until Learn runs) |
| `clients[].changelog_head[]` | first 12 lines of `CHANGELOG.md` |
| `clients[].kpis[]` | the KPI table in `strategy.md` (kpi, source, target) |
| `clients[].journal_recent[]` | last 30 `journal` rows (id, ts, action, target) |
| `clients[].listen.{comments_waiting, dms_waiting}` | null until `listen/` is deployed |
| `clients[].ga4.sessions_by_campaign` | null until `ga4.py` runs |
