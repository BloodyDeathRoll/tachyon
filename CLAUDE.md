# Tachyon — project rules

STAY CONCISE. ANSWER ONLY IN THE SHORTEST SIMPLEST TERMS.
DO NOT GIVE SUMMARIES. DO NOT GIVE EXPLANATIONS UNLESS ASKED.

- Report facts, decisions needed, and blockers. Nothing else.
- No recap of what was done. No "cause" paragraphs. No restating the plan.
- One line per item. Code, commands and error text in a fenced block.
- Plan: `docs/PLAN.md`. Playbook: `docs/PLAYBOOK.md`. Rule 13: never "comment for the link".
