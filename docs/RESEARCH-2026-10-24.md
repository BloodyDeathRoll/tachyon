## 1. instagram-agent-skill (Jakeschincariol), read in full — V

- 13 `SKILL.md` files + 6 Python tools (1,466 lines, stdlib only) + 3 JSON data files. MIT. Last
  commit 2026-09-13. Sibling repo linkedin-agent-skill (1.2k stars).
- **Data worth taking as-is:** `hooks.json` (26 formulas: template, example, on-screen line, purpose,
  failure mode, match regex), `slop.json` (96 words, 58 phrases, 18 invisible-char classes, 11
  typographic swaps, 16 structural tells), `rubric.json` (12-item, 100-point profile score),
  `templates/voice.md`.
- **Tools worth taking as-is:** `hookscore.py` (5-property hook panel; author's own test: AUC 0.83 at
  rejecting bad hooks, **0.56 at picking winners**, so use it as a floor, not a predictor),
  `beats.py` (script → timed beat sheet, flags hook >3 s, beat >4 s, no loop), `caption.py`
  (125-char feed window, one ask, ≤5 hashtags, search terms), `humanize.py` + `detect.py`,
  `swipe.py` (outlier multiple = views / account median; formula classifier).
- **Process logic worth taking:** `ig-plan` (weekly mix: proof / teach / opinion / story / offer; 3+
  reels of 4–5 posts; engagement list 5 reach / 3 peers / 2 buyers), `ig-audit` (rank by outlier
  multiple and sends per reach; hold@3s is the hook grade; "views without follows = profile
  problem, no views = hook problem"; day/time checked last), `ig-reply` (six buckets: keyword /
  lead / substance / question / support / noise; a popular question becomes a Reel, formula #16),
  `ig-comment` (nine comment types; never pitch), `ig-dm` (only reply to a raised hand; keyword
  delivery first, no gate; two follow-ups max), `ig-viral` (6–12 accounts within 10× own size,
  median per account, YouTube Shorts as a public second corpus via yt-dlp), `ig-repurpose`
  (extract claims / numbers / stories / mechanisms / mistakes / lines).
- **Memory contract:** `~/.claude/instagram/{voice.md, plan.md, swipe.md, log.md}`; every skill
  reads voice.md, plan reads swipe + log, audit writes back to plan and viral.
- **Hard limits:** no API, no rendering, no scheduling, no metrics ingestion. Humanizer is
  heuristic, not a detector. Hashtag cap of 5 (2025-12-18) is the repo's claim, not re-verified
  (Meta help pages are JS-rendered; search budget exhausted) — **U**.

## 4. Existing solutions (survey) — A, spot-checked

- **No product covers plan + generate + video + publish + engage + measure + learn for Instagram.**
  Stacks are a reasoning layer (Claude / n8n / Lindy / Okara) over a publishing API (Postiz,
  Blotato, Zernio, Ayrshare, upload-post, Metricool). MCP is the seam everywhere.
- Learning from performance is almost absent. Lately.ai (voice model refit on top posts) and UGC
  King (auto variant tests of winners, $5–10 per video) claim it; neither exposes the loop.
- Engagement on other accounts' posts: no compliant product does it automatically. Hypefury's
  "Engagement Builder" (surface targets, human posts) is the compliant pattern.
- **Postiz** (AGPL, 37.7k stars, V): hosted MCP + `postiz-agent` skill; **cannot read or reply to
  comments or read analytics** (docs, V). Clipping and AI video on cloud plans.
- **Zernio** (ex-Late, V): 2 accounts free, unlimited posts, Reels, comment replies, analytics,
  MCP. Rebrand 2026 and reported price hikes for legacy users.
- Blotato ($29, MCP, comments/DMs only for posts it published), Ayrshare ($149/profile, best
  engagement automations), Metricool (open-source MCP, free tier analytics, best-time,
  competitor posts), Opus Clip (clip + auto-post API, needs long-form source).
- Video gen: **Sora API removed 2026-09-24 (V)**; Veo gone from the Gemini API 2026-10-22 (A);
  Gemini Omni 1.1 Flash ≈ $0.10/s 9:16 with SynthID (A); Veo on Vertex (A). Avatar/voice: HeyGen,
  Captions Mirage, ElevenLabs (TTS, STT with word timestamps, Music API).
- Renderers: **Remotion** free for teams ≤3 incl. commercial (V), deterministic frames,
  `@remotion/captions`, official skills repo (5.6k stars). Revideo stale, Motion Canvas not
  headless, Editly dead. Hosted JSON renderers: Creatomate, Shotstack.

## 6. ChatGPT brief — what it adds (read in full)

Adds: content-item state machine with exception states; idempotency on publish; asset provenance
and licence records; product-level measures (human minutes per approved post, cost per asset,
publish failure rate, analytics completeness, issues caught pre-publish); experiment schema with
guardrail metrics and a "directional only" label; "heuristic scores are not predictions"; emergency
stop; per-scene replaceability; pointer to the Anthropic marketing plugin.
Does not fit: multi-tenant TypeScript SaaS (25 entities, React command center) for a single
operator; defers all engagement; re-asks decisions already made (Rosa first, Instagram first,
Claude brain, PC runtime).
